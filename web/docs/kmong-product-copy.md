# 크몽 상품 문안

상품 가격과 옵션 가격을 표시하는 영역에 다음 각주를 함께 노출합니다.

> 모든 가격은 홈페이지 1개 기준입니다.

표시 문구의 단일 소스는 `web/src/lib/pricing.ts`의 `SITE_PRICE_UNIT_COPY`입니다. 홈페이지를 추가하려는 고객에게는 홈페이지마다 월 구독이 각각 적용되며, 두 번째 홈페이지는 별도 문의로 안내합니다.

## 가격·결제 안내

> 먼저 만들어 보여드립니다. 발행할 때만 결제하세요.

> 홈페이지 1개 · 월 150,000원 · 매월 자동 갱신 · 별도 제작비 없음 · 부가세 별도

> 연납 선택 시 연 1,500,000원 · 월납 대비 2개월 무료

스탠다드 월 이용료에는 다보임이 만드는 사이트와 커넥터, 전환 추적, 월간 리포트,
기초 검색·AI 대비와 구조화 정보, 호스팅·운영이 포함됩니다. 고급 AEO와 지속적인
AEO 콘텐츠, 더 넉넉한 편집 의뢰가 필요한 프리미엄은 상담 후 안내합니다.
광고 매체 집행비는 포함되지 않습니다.

레이아웃 선택, 절차적 배경, 제공 스톡처럼 외부 생성비가 들지 않는 기본 자산은 크레딧 없이 포함합니다.
AI 이미지·영상처럼 외부 생성비가 드는 프리미엄 작업과 다보임 수정 대행에만 크레딧을 사용합니다.

성과 보장 프로그램은 파일럿 전후 데이터와 법률 검토가 끝날 때까지 상품 문안에서 잠정 제외합니다.
자동 갱신 해지·환불 조건과 부가세 표시 방식은 실제 결제 기능 오픈 전 법률 검토 후 확정 문안으로 교체합니다.

## 제작·수정·영상 적용 기간

> 홈페이지 제작은 영업일 3일 이내 완료됩니다.

> 수정 대행은 접수 후 영업일 1~2일 안에 처리됩니다.

AI 영상 홈페이지 옵션에는 다음 안내를 함께 노출합니다.

> 주문 후 영업일 1~2일 안에 적용됩니다. 사장님이 고르신 연출 방향대로 다보임 AI가 만들고, 한 편씩 직접 검수해 가게 분위기에 맞는 것만 올립니다.

기간과 안내 문구의 단일 소스는 `web/src/lib/fulfillment-sla.ts`입니다. 크몽 문안을 갱신할 때 이 파일의 고객 노출 문자열과 일치하는지 확인합니다.
