# Latin font asset notices

These checked-in WOFF2 files are deterministic Latin subsets of checksum-pinned official sources.
No runtime request is made to Google Fonts, IBM, or another font CDN.

- Schibsted Grotesk, Hanken Grotesk, Albert Sans, and Public Sans — SIL Open Font License 1.1; pinned source: https://github.com/google/fonts/tree/9fab8b6cc7b2f20376914fd765d918c698c66d75/ofl
- IBM Plex Sans — SIL Open Font License 1.1; pinned source and license: https://github.com/IBM/plex/tree/242c4cccd37e87985a5337815c99b960ef13c65c

The original family names are retained to identify and load the licensed fonts.
