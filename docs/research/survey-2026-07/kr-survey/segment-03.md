# 국내 병원 웹사이트 실측 — 세그먼트 03 (site-list.txt 28~40번, 13곳)

측정: 로컬 Playwright/Chromium headless. 데스크톱 1440×900 · 모바일 390×844 두 패스.
DOM computed style 계측 + 섹션별 실제 렌더 픽셀 휘도(전체 스크롤 후 캡처, 메모리 내 계산·비저장).

**휘도 판정 임계값**: 상대휘도 L = (0.2126R+0.7152G+0.0722B)/255, 섹션 밴드 평균.
`라이트` = 평균 ≥ 0.65 또는 밝은픽셀(L>0.65) 비율 ≥ 0.60 · `다크` = 평균 ≤ 0.35 또는 어두운픽셀(L<0.35) 비율 ≥ 0.60 · 그 사이는 `mixed`(사진 위 텍스트 오버레이가 대부분).

**표기**: `auto` = 스크립트 실측값 그대로 · `judged` = 실측 데이터를 근거로 내가 분류/코딩한 값 · `unverified` = 측정 실패·미확인.

**준수**: HTML/CSS 코드·이미지·카피 문구·색상 hex·아이콘 수집 0. 구조/유형/빈도/수치만 기록. 문구는 성격만 기술하고 인용하지 않음. 자산 다운로드 0.

**섹션 수 주의**: 스크립트가 DOM 트리를 재귀 분할해 섹션을 잡는다. 400px 미만의 미세 블록이 섞이므로 `의미섹션(h≥400px)`을 기준 수치로 쓰고 raw 카운트를 병기한다.
