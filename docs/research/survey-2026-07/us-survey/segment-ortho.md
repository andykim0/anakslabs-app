# 미국 정형외과·척추·스포츠의학·일반외과 클리닉 홈 구조/톤 실측

측정일: 2026-07-31 · 대상 8곳 · 측정 기준: 각 사이트 **홈 1페이지**

## 측정 방법 (실측 경로)

- 로컬 Chrome(정식 바이너리)을 CDP로 구동해 **실제 라이브 URL을 렌더**했다. 하네스·목업·정적 HTML 파싱이 아니다.
- 데스크톱 1440×900 / 모바일 390×844 두 번 로드. 각 로드에서 전체 페이지를 끝까지 스크롤해 지연 로딩을 유발한 뒤 상단으로 복귀.
- 두 갈래로 측정해 교차검증:
  1. **DOM 계측** — 풀폭 밴드(섹션) 추출, 섹션별 본문 길이/이미지 수/캐러셀 수, 계산된 폰트, position:fixed·sticky 요소, 모션 라이브러리 존재 여부.
  2. **픽셀 계측** — 전체 페이지 PNG 캡처를 직접 디코드해 **행 단위 평균 휘도**를 계산하고 섹션 y범위에 매핑. 다크/라이트 판정은 배경색 선언이 아니라 실제 렌더 픽셀 기준(휘도 <110 다크, 110–165 중간, >165 라이트).
- 캡처 이미지는 전부 **육안 확인**했다. DOM 휴리스틱이 틀린 지점(예: 히어로 헤드라인이 사진 위 오버레이가 아니라 사진 아래 별도 밴드인 경우)은 육안 판정으로 교정했다.
- 부재("없음") 판정은 잘린 출력이 아니라 **홈 전체 innerText 전수 grep + 전체 페이지 캡처 육안 확인** 두 가지를 모두 통과한 경우에만 기록했다. 확정 불가는 "미확인"으로 남겼다.
- 접근 차단·로그인 요구로 우회가 필요한 사이트는 없었다. 8곳 모두 HTTP 200 정상 렌더.

**준수선**: HTML/CSS 코드·사진·카피 문구·색상 hex·아이콘을 일절 수집하지 않았다. 자산 다운로드 0. 아래 기술은 구조·유형·빈도만 담는다. (계측 중 생성한 화면 캡처는 판정용 로컬 산출물이며 사이트 자산이 아니다.)

**선정 기준**: 검색 순위·광고 노출은 선정 근거로 쓰지 않았다. ① 개인 개원의·소규모 독립 그룹일 것(대형 병원 시스템 제외), ② 세그먼트 4갈래(정형/척추/스포츠의학/일반외과)에 분산, ③ 디자인 에이전시 큐레이션 수록 또는 자체 브랜드 사이트로 디자인 투자가 확인될 것.
