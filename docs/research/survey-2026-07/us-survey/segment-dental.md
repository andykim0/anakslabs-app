### 0.2 heroLum (히어로 배경 밝기) 정의와 임계값

CSS `background-color`만으로는 히어로가 이미지·영상 배경일 때 밝기를 판정할 수 없다(실제로 절반 이상이 미디어 배경이었다). 따라서 **렌더된 픽셀의 상대 휘도**를 직접 계산했다.

- 측정법: 스크롤 최상단에서 뷰포트(1440x900)를 렌더 → 픽셀 RGB를 `L = (0.2126R + 0.7152G + 0.0722B) / 255` 로 변환 → 평균(`mean`), 어두운 픽셀 비율(`darkFrac` = L<0.35), 밝은 픽셀 비율(`lightFrac` = L>0.65) 산출
- 임계값: **`mean ≤ 0.35` 또는 `darkFrac ≥ 0.60` → 다크** / **`mean ≥ 0.65` 또는 `lightFrac ≥ 0.60` → 라이트** / 그 외 → **mixed**
- 근거: 0.35/0.65는 상대 휘도 축의 3분할 경계로, 밝은 사진 위 검정 텍스트(라이트)와 어두운 사진 위 흰 텍스트(다크)를 가르는 지점이다. 어느 쪽으로도 60% 이상 쏠리면 평균이 중간이어도 해당 극으로 판정하도록 보조 조건을 뒀다(예: 좌 흰 배경 + 우 어두운 사진 분할 히어로는 mixed로 남는다).
- 섹션별 밝기도 같은 방식으로, 각 섹션 중앙을 뷰포트에 놓고 해당 밴드의 휘도를 계산했다. **밝기 전환 횟수는 이 섹션별 판정의 인접 변화 수**다.
- 이미지 픽셀은 계산에만 사용하고 저장하지 않았다. 디스크에 기록된 것은 위 수치뿐이다.

### 0.3 auto / judged / unverified 구분

각 카드의 항목에 다음을 표기한다.

- **auto** — 하네스가 직접 산출한 수치·불리언. 스크롤 길이, 섹션 수, 섹션당 본문 글자 수, 섹션당 이미지 수, heroLum, 폰트 family 문자열, 배경색 계열 수, 밝기 전환 횟수, 고정/스티키 요소의 위치·크기·링크 프로토콜, 리빌 후보의 opacity/transform 변화량
- **judged** — 하네스 산출값을 사람이 해석해 유형으로 분류한 것. 표준 블록 8종 유무, 모션 유형과 강도, 플로팅 CTA 형태, 히어로 이미지 배치, 서체 계열(세리프/산세리프/디스플레이)
- **unverified** — 측정 실패·미노출·판정 불가. 추정으로 채우지 않는다

### 0.4 선정 기준

- 검색 순위·광고 노출은 선정 근거로 쓰지 않았다(순환 논증). 대신 **제3자 디자인 쇼케이스/어워드 등재**를 근거로 삼았다.
- 대형 체인(전국 단위 DSO)은 제외, 개인 병원·소규모 그룹 우선.
- 미국 소재 여부는 페이지 내 **주(州) 약어 + ZIP 패턴**과 **미국 전화번호 형식**으로 확인했다(카드에 기재).
- 접근 차단·로그인 요구 시 우회하지 않고 "접근 불가"로 기록하고 다음 후보로 대체한다.

**D. 공통 골격**
