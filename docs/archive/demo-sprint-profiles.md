# 데모 스프린트 — 업종 프로필 5종 (온보딩 입력값 세트) · v4

목적: 단일 제품(다보임) 흐름을 실사용 경로로 검증. 5건 모두 **base 제품**이고, 영상은
별도 **애드온**(일부만 선택). 모든 프로필은 가상 — 실존 상호와 무관, 가상 정보를 실제처럼 입력.

> **v4 개정 — 그동안 쌓인 전부 반영**: 단일 제품(플랜 선택 없음, 회원가입→온보딩) ·
> 레퍼런스 갤러리 선택(R) · 4단계 승인 프레이밍(A4) · 와이어프레임 확인 게이트(A3) ·
> 페이지 우선순위 필수/선택(A2) · 구체적 피드백(A5) · 움직임=기본효과 vs 영상애드온(H3) ·
> 배경 파랑 홍수 제거(H2) · 개선 모드 스피너 수정(H1). 제품명은 **다보임**.

## 전 사이트 공통 체크포인트 (누적 검증)

**흐름 (A4 4단계 승인):**
- [ ] 회원가입 → 온보딩 (플랜 선택 화면 없음 — 단일 제품)
- [ ] 레퍼런스 갤러리(R): 실제 미리보기 그리드에서 뼈대·톤·색 선택 (업종 기본 추천 정렬)
- [ ] 움직임(H3): **기본 효과(무료)** vs **영상 배경(애드온 +20만)** 두 묶음으로 구분 노출
- [ ] 구성 확인(A3 와이어프레임): "이 구성으로 만들게요" → 1클릭 통과 or 섹션 빼기
- [ ] 4단계 진행 표시("2/4 디자인 방향" 등) + 언제든 이전
- [ ] 우선순위(A2): 홈·소개·연락이 필수(must) 기본, "빼기만" 가능

**생성물 품질 (Q·D·H 누적):**
- [ ] 히어로 카피 또렷이 읽힘(스크림 Q1) + 뷰포트 1개 높이감(D2)
- [ ] **배경 파랑/원색 홍수 없음** — 밴드는 흰/틴트/다크만 (H2 채도 가드 ≤0.16)
- [ ] 홈이 한 페이지로 연속(배경 조각 없음, D2)
- [ ] 메뉴/항목: 입력한 것 전부 그리드(G3), 같은 사진 2곳+ 없음(Q4)
- [ ] 프리뷰 "모션" 기본 재생 — ken-burns/reveal 체감(G1), 토글 OFF/ON 이미지 복구(D1)
- [ ] 발행 누르면 SEO/AEO/GEO 진단·보완 가이드 화면(G4) — 점수 82(B)대 정직(P)
- [ ] 모바일: 카드 단위 스택 + 햄버거 내비 + 생성 직후 가이드 카드

## 1. 소소한자리 — 동네 카페 (음식점·로컬)

- 목적: 손님 받기 → 음식점·로컬 매장 / 상호 소소한자리 / 지역 **서울 서대문구 연희동**
  / 태그라인 "매일 아침 굽는 빵과 계절의 커피"
- **레퍼런스 갤러리**: 웜 코지/에디토리얼 계열 카드 선택 (미리보기에서 따뜻한 톤 확인)
- **레퍼런스 URL(A1, 선택)**: 미입력 — 갤러리 선택만으로 진행 (미입력이 정상)
- 이미지 스타일: 실사(photo) — '추천' 뱃지 확인
- 콘텐츠 원료(providedContent) + 구조화 메뉴 항목(G3):

```
[소개]
서울 연희동 골목의 8평짜리 동네 카페입니다. 매일 아침 6시에 반죽해 굽는 빵과
직접 로스팅한 원두로 내리는 커피를 만듭니다. 2022년 문을 열었고, 단골 손님의
절반은 이름을 알고 지냅니다.
[메뉴] 아메리카노 4,500 / 카페라떼 5,000 / 벚꽃라떼 6,500 / 크루아상 4,200 /
앙버터 5,500 / 소금빵 3,800 / 딸기 타르트 7,000
[영업] 화–일 08:00–20:00 (월 휴무) / 서울 서대문구 연희로 00길 12, 1층
[하고 싶은 말] 빵 나오는 시간(8시·14시) 안내를 눈에 띄게.
```

- 사진: 전부 건너뛰기 + 로고 없음 ← **AI 보충·글자 로고 검증** ([image-pool] 로그 대조)
- 우선순위(A2): 홈·소개·메뉴·연락 필수, 갤러리는 선택으로 두고 "빼기" 시연 가능
- 움직임: **기본 효과** "사진이 천천히 커지는 느낌"(ken-burns) — 영상 애드온 미선택
- 자랑거리(A/G): 매일 아침 6시 반죽 / 직접 로스팅 / 빵 나오는 시간 안내
- 콘텐츠 게이트(G3): 메뉴 7개 입력했으니 통과 — 미입력 시 진행 차단되는지도 1회 확인

**기록**: 생성 __분 / 원가 ₩__ / AI 보충 __장 / 수동 수정 __곳 / 이슈: ___

  지역 **경기 성남시 분당구** / 태그라인 "성적보다 습관을 먼저 만드는 수학 학원"

## 6. 보너스 테스트 4건 (프로필 생산 후)

1. **개선 모드(I)**: 새 설문 말고 무료진단 → "다시 만들기"로 anakslabs.com improve →
   H1 스피너 안 막힘 + 팔레트 추출(파랑) 밴드 홍수 없음(H2) + 전후 점수 대조(I4) 확인.
2. **와이어프레임 빼기(A3)**: 한 프로필에서 nice 섹션 하나 빼고 생성 → 그 섹션만 빠지는지.
3. **구체 피드백(A5)**: 완성본에서 "색 바꾸기 → 더 차분하게" 구조화 칩 → 결정적 반영.
4. **발행 preflight(G4/P)**: 5개 발행 시도 → SEO/AEO/GEO 점수 기록(파리티 후 82대 기준선).
