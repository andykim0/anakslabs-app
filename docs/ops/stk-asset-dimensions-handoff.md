# STK 자산 치수 서버 계약 이관 메모

작성일: 2026-07-23

ABS 정찰 시 연결된 운영 데이터에서 사이트 2개, 갤러리 이미지 URL 3개를 확인했지만
`asset_records` 행은 0개였다. 따라서 registry 행 기준 결측률은 계산할 수 없고,
현재 갤러리 자산의 서버 소유 `width`/`height` 메타데이터 유효 결측률은 3/3(100%)이다.

이 결함은 절차적 배경 작업과 분리해 STK 배치 계약으로 이관한다. ABS에서는 DB 필드,
업로드 처리, 마이그레이션이나 백필을 구현하지 않는다.

STK 구현 항목:

- `asset_records.width`와 `asset_records.height`를 서버 소유의 양의 정수 필드로 추가한다.
- 직접 업로드와 customer import 인제스트 시 서버가 파일을 디코딩해 치수를 기록한다.
- 기존 레코드는 원본 접근이 가능한 자산만 결정적으로 백필하고, 접근 불가 행은 명시적
  미확인 상태로 남겨 추측한 치수를 기록하지 않는다.
- 갤러리 렌더·피커는 이 서버 메타를 사용해 CLS와 비율 선택을 검증한다.

자산 레코드가 없는 URL 참조는 STK 마이그레이션 전에 provenance·소유권을 확인한 뒤
레코드화해야 한다. 외부 URL의 응답 헤더나 파일명만으로 치수를 추정하지 않는다.
