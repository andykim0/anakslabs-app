# 검색 등록 대행 운영 절차

이 문서는 비밀번호나 인증 코드를 보관하지 않는다. 관리자 큐에는 `NAVER-OPS-01` 같은 운영 계정 라벨만 기록한다.

## 적용 원칙

- 다보임 서브도메인과 커스텀 도메인 모두 사이트별 `naver-site-verification` 값을 `<head>`에 넣는다.
- 구글은 다보임 루트 도메인을 DNS 방식 Domain property로 한 번 확인하면 그 아래 프로토콜·서브도메인을 함께 다룰 수 있다. 커스텀 도메인은 해당 도메인의 소유확인 값을 따로 기록한다.
- 네이버는 사이트별로 Search Advisor에 등록하고 소유확인을 완료한다. 검색 등록과 실제 검색 노출은 같은 뜻이 아니며, 등록은 색인 현황을 운영 화면에서 확인하기 위한 절차다.
- 발행 뒤 IndexNow 제출 배선은 이 절차와 별개로 그대로 유지한다.

## 사이트 1곳 처리 순서

1. 관리자 `검색 등록` 큐에서 사이트 주소와 도메인 종류를 확인한다.
2. 네이버 Search Advisor에서 발급받은 메타태그의 `content` 값만 큐에 입력한다.
3. 구글 메타태그 확인이 필요한 커스텀 도메인은 구글 값도 입력한다. 다보임 서브도메인은 루트 Domain property 확인 상태를 먼저 확인한다.
4. `저장` 후 실제 사이트의 `<head>`에 값이 나타나는지 확인한다.
5. 네이버 운영 계정으로 사이트를 등록하고 소유확인을 누른다.
6. 큐의 `등록 상태`를 완료로, `네이버 색인`을 확인 결과대로 기록한다. 이 색인 값은 90일 성과 보장판의 숫자 근거로도 사용된다.

## 네이버 운영 계정 전환

- 운영 정책상 계정당 등록 상한은 100곳으로 관리한다.
- 완료 사이트가 80곳에 도달하면 관리자 화면에 `다음 계정으로 전환` 경고가 뜬다.
- 경고가 뜨면 신규 사이트에 다음 번호의 계정 라벨을 지정한다. 자동 전환하지 않는다.
- 100곳에 도달한 계정으로 새 완료 기록을 저장하면 서버가 거부한다.
- 계정 목록: `NAVER-OPS-01`, `NAVER-OPS-02`, 이후 같은 규칙. 실제 로그인 정보는 승인된 비밀 관리 시스템에서만 관리한다.
