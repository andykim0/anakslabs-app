# 네이버 플레이스 등록 같이 하기

플레이스 등록은 사장님 계정이 필요해요. 가이드를 드리고 같이 진행해 드립니다.

## 준비해 주세요

- 사장님 명의 네이버 계정
- 사업자등록증에 적힌 상호·주소·대표자 정보
- 가게 전화번호와 영업시간
- 가게를 잘 보여주는 실제 사진

## 함께 진행하는 순서

1. 사장님이 네이버 스마트플레이스에 로그인합니다.
2. 화면의 `업체 신규 등록`을 누르고 사업자 정보를 입력합니다.
3. 업종·전화·영업시간을 실제 정보와 맞춥니다.
4. 사장님이 가진 실제 사진을 올립니다.
5. 네이버가 요청하는 확인 절차를 사장님 계정에서 마칩니다.
6. 다보임이 홈페이지의 상호·주소·전화·영업시간이 플레이스와 같은지 함께 확인합니다.

다보임은 사장님 대신 계정 비밀번호를 받거나 보관하지 않습니다. 플레이스 승인 여부와 노출 방식은 네이버가 결정합니다.
